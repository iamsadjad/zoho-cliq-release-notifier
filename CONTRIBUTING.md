# Contributing

```bash
git clone https://github.com/iamsadjad/zoho-cliq-release-notifier.git
cd zoho-cliq-release-notifier
make all
```

Requires Go 1.22+.

Commits on `main`:

- `fix:` → patch
- `feat:` → minor
- `BREAKING CHANGE:` / `feat!:` → major

Keep PRs focused and ensure `make all` passes.
